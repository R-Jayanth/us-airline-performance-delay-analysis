# U.S. Airline Performance & Delay Analysis

## Project Overview
An interactive Power BI dashboard developed to analyze U.S. airline performance, flight delays, on-time performance, cancellation rates, and airport-level trends.

## Dashboard Highlights

### Key Performance Indicators
- Total Flights
- Average Arrival Delay
- On-Time Performance Rate
- Cancellation Rate

### Flight Delay Analysis
- Distribution of flight delay types, including airline, weather, security, and late-aircraft delays
- Average arrival delay by airline
- Average arrival delay by origin airport
- Top 10 airports with the highest average arrival delays

### Operational Trends
- Flight volume trends by month and day
- Average arrival delay by month
- On-time, delayed, and cancelled flight status analysis
- Airline delay analysis by system, weather, aircraft, and arrival factors

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Dashboard Development
- Exploratory Data Analysis

## Key Dashboard Observations
- The dashboard displays approximately 6 million flights.
- The displayed on-time performance rate is 82.41%.
- The displayed average arrival delay is 4.4 minutes.
- Airport and airline comparisons highlight differences in average arrival delays.
